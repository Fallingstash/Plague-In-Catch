# Сопоставление реализаций VACV

Новые замеры выполнены на train.csv, одинаковые пять canonical-групповых разбиений CPU-пайплайна, seed 42, epochs 60, 2 сети на конфигурацию, CPU, только SMILES. Для сравнения base CPU был заново обучен с --smiles-only. Параметры исторической версии, давшей пользовательский Kaggle score 1 365 716, по имеющимся артефактам не восстановлены; это не доказанное воспроизведение той модели.

| Вариант | OOF MSE |
|---|---:|
| CPU log | 4 221 100 |
| VACV neural log | 4 245 445 |
| VACV neural hybrid | 4 322 606 |
| CPU ExtraTrees | 4 357 006 |
| CPU Tanimoto kNN | 4 624 164 |
| Предварительно заданная смесь 50% neural log + 50% kNN | 4 302 377 |
| CPU ансамбль, веса выбраны на этих OOF | 4 190 511 |
| Исправленный CPU ансамбль, веса выбраны на этих OOF | 4 190 501 |

Ансамбли выбирают веса по тем же OOF, поэтому их оценки оптимистичны. Все фолды включены; разница 9 MSE между ансамблями ничтожна и не является доказательством улучшения. Худшая ошибка связана с крайне большим SI. Один публичный score не позволяет выделить причину расхождения или гарантировать качество на скрытой части.

Различия: CPU использует KNN и ExtraTrees в дополнение к сетям, по умолчанию может добавлять культуру и штамм, имеет отдельные raw/log/hurdle головы, log-MSE, другую ширину сети, распределение по фолдам и выбор весов ансамбля. Neural использует log-Huber или hybrid с иной архитектурой и другой стратификацией. CPU усредняет разные модели, а не одну сеть. В старой CPU-реализации внутренний выбор эпох использовал масштабирование, подогнанное на внешнем обучающем фолде, включая внутреннюю валидацию; в отдельном vacv_cpu_improved.py это исправлено. Верхнее ограничение CPU log-предсказания 40000 заменено ограничением численного переполнения exp. Во время финального fit ExtraTrees число деревьев 350, а в CV 250; этот оставшийся источник различия необходимо учитывать. Метаданные вне SMILES не проверены на разрешённость правилами, поэтому использован --smiles-only.

Проверены формат 597 строк и соответствие sample, неотрицательность и конечность результата, совпадение после загрузки модели (максимальное отклонение 2.3e-13). Для честного подтверждения улучшения требуются повторные внешние разбиения и вложенный подбор весов ансамбля. Предыдущая лучшая модель не заменена.
