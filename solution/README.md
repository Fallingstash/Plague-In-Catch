# VACV: прогноз индекса селективности

Решение задачи регрессии: по SMILES предсказывается `SI VACV`. Метрика соревнования — MSE на исходной шкале. По сообщению команды, результат сохранённого файла `versions/top1/submission.csv` на Kaggle — **886520.98398**. Для воспроизведения используется сохранённый ансамбль: 70% CPU-модели и 30% GCN. Обучение использует только официальный train (320 строк); test используется только для предсказаний.

## Запуск и воспроизведение

Из каталога `solution` в Python-окружении установите зависимости: `python -m pip install -r requirements.txt`. Проверенное окружение и версии пакетов перечислены в `experiments/research_20261107/environment.txt`; точные версии зависят от платформы и доступности сборок PyTorch и RDKit.

```bash
python -m src.cli validate-submission --file versions/top1/submission.csv
python -m src.cli make-submission --output output/submission.csv
```

Первая команда сверяет формат, контрольные суммы и прогнозы сохранённой модели. Вторая создаёт новый CSV и проверяет его; выберите новый путь, если файл уже существует. Формат — `index,SI VACV`, 597 строк в порядке test. Незначительные различия в последних знаках чисел возможны из-за окружения. Загрузка на Kaggle выполняется отдельно.

## Обучение и оценка

```bash
python -m src.cli train --device cpu --out output/training
python -m src.cli evaluate --cv canonical --seeds 42,43
```

Обучение создаёт новый checkpoint по фиксированному рецепту; оно не гарантирует побайтное воспроизведение исторических весов и результата Kaggle. Оценка группирует одинаковые канонические SMILES по фолдам; использует все фолды и не использует test для подбора. Реально использованные обучающие SMILES и SI приведены в `experiments/research_20261107/official_training_used.csv`. Входные данные `train.csv` проверяются по SHA-256. Подробный код обучения и проверки — `src/research.py` и `src/validation.py`.

## Открытые данные

`python -m research_data_collection collect` загружает записи ChEMBL, сохраняя источники. Исходные адреса и ограничения описаны в `research_data_collection/README.md`. `python -m research_data_collection export --out output/research` формирует таблицу из включённого промежуточного файла. В `research_data_collection/exports/research_candidates.csv` находятся 59 кандидатных пар с SMILES, IC50, CC50, SI, DOI и ссылкой. Они ожидают проверки совместимости по первоисточникам; проверенных пар пока **0**, и внешние данные не использовались для обучения конкурсной модели. Поэтому утверждать, что требование о проверенной внешней базе полностью выполнено, нельзя.

Сохранённый pipeline проверен в существующем локальном окружении; переносимость на других версиях зависимостей следует проверять отдельно. Научный результат является прогнозом модели, а не экспериментальным подтверждением активности.
